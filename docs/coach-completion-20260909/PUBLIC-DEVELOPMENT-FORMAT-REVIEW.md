## Reassessment against the actual product question contract

The product says 1–5 focused questions, not one requested value per person. Multiplying a single behavior question merely because it covers several participants imposed a stricter rule absent from `docs/AGENT-SPEC.md`. That interpretation is withdrawn. This correction also applies prospectively to the conservative participant counts in earlier reviews; no previous model output or machine receipt is changed.

A focused question asks one topic or field. Asking what each member did next remains one behavior question; asking contacted count and problem-report count asks two different fields. On that basis, the evidence opening has four focused questions, or five if its request to classify the remaining reports is counted separately. The experiment opening has five: contacted count, problem-report count, subsequent behavior, availability of a test occasion, and threshold choice. Both meet the product ceiling. This rule avoids making an identical question fail merely because a supplied group is larger.

# Use the coach during the hackathon

Claude Code with provided API access: start a separate conversation in the repository,
load the coach prompt you created in your own build folder and ask it to act as
that coach. Ask it not to edit or build yet.
Claude chat: paste your complete coach prompt into a fresh chat on your eligible account.
API credits do not promise a Claude chat subscription. Follow the organizer's access setup.

## First message
My idea is ____. The person I want to help is ____.
The last time I observed this problem was ____.
They currently handle it by ____.
Before judging, I can reach ____.
Help me decide what to investigate first.

Answer with actual observations or clearly labeled assumptions. Unknown is useful.
For practice, label the entire scenario synthetic and keep real fieldwork Unknown.
Supply source excerpts with URLs and access dates when browsing is unavailable.

## Ask for the outputs
Draft all four outputs from what I supplied. Keep Unknowns and source attribution.
Do not invent missing facts.

Save the Idea Brief, Count Ledger, Experiment Card and MVP Brief in your project docs.
Choose Proceed, Narrow, Investigate or Pivot yourself and explain why.
Return after your test with actual results; ask what they establish and what remains unknown.
